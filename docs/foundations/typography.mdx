# Typography

Guidelines for type scale, font families, and readable text. Example tokens illustrate the core → semantic → text-style pattern.


## Text styles

Use a named text style instead of combining size and weight by hand:
Typography establishes hierarchy and readability. Core tokens hold raw values; semantic tokens name size/weight/leading roles; **text styles** (composites) package those into usable recipes for UI and agents.

| Token | Class | Typical use |
|-------|-------|-------------|
| `text.heading.1` … `6` | `.text-heading-1` … (also `h1`–`h6`) | Document hierarchy |
| `text.body` | `.text-body` | Paragraphs, descriptions |
| `text.label` | `.text-label` | Form labels, buttons, navigation |
| `text.caption` | `.text-caption` | Captions and fine print |
| `text.code` | `.text-code` | Inline code / monospace |

Defined in ../tokens/composite/typography.composite.json. On the docs site they regenerate into `site/src/styles/generated/text-styles.css`.

## Semantic building blocks

Pieces that text styles reference — use these only when defining or extending a text style, not as the default API in UI:

| Group | Examples |
|-------|----------|
| Family | `text.style.base`, `text.style.display`, `text.style.mono` |
| Size | `text.size.xs` … `text.size.4xl` |
| Weight | `text.weight.normal`, `medium`, `semibold`, `bold`, `extrabold` |
| Leading | `text.leading.xs` … `text.leading.lg` |
| Letter spacing | `text.letterSpacing.xs` … `text.letterSpacing.lg` |

File: [typography.semantic.json](https://github.com/jcmartinezma/bravo-agentic-design-system/tree/main/docs/tokens/semantic/typography.semantic.json).
