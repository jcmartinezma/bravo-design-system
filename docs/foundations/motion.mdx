## When to animate

**Do animate:** state changes the user triggered; spatial relationships (drawer, tooltip).

**Do not animate:** critical errors; decorative motion on data-heavy screens; anything that ignores `prefers-reduced-motion`.

## Accessibility

- Motion supports understanding (feedback, orientation) but can distract or harm accessibility if overused.
- Honor **`prefers-reduced-motion: reduce`** — provide instant or minimal alternatives.
- Never block interaction until an animation completes unless necessary (and keep it short).
