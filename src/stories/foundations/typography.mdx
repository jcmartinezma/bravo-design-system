# Typography

Guidelines for type scale, font families, and readable text. Example tokens illustrate the core → semantic → text-style pattern.

## Text styles

Use a named text style instead of combining size and weight by hand. Core tokens hold raw values; semantic tokens name size/weight/leading roles; **text styles** (composites) package those into usable recipes for UI and agents.
