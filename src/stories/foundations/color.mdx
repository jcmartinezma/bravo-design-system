# Color

Color defines hierarchy, state, and brand. This doc describes *roles* (what each color is for). Values live in the [token files](?path=/docs/foundations-tokens--docs).

This starter includes **example tokens only** — extend or replace them for your brand.

## Light and dark

Light is the default mode. Optional dark overrides live in `tokens/theme/dark/color.semantic.json`.

## Accessibility

- Text on backgrounds must meet **WCAG 2.1 AA** contrast (4.5:1 normal text, 3:1 large text).
- Do not rely on color alone — pair with icons, labels, or patterns.
- Test semantic colors with common color-vision deficiencies.
