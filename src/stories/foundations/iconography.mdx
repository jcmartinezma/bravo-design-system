# Iconography

Icons reinforce actions and status. SVG sources live in `public/svg/`; React components are generated into `src/icons/` and use `currentColor` so they inherit text or icon color tokens.

## Usage

Import by component name or look up by kebab-case name:

```tsx
import { Search, icons } from '../../icons';

<Search />
const Icon = icons['search'];
```

Pass the kebab-case name to components that accept `IconName` (for example Button `leadingIcon` / `trailingIcon`):

```tsx
<Button label="Search" leadingIcon="search" />
```
