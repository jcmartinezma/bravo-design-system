# Contributing

Thank you for helping improve the Agentic Design System starter. This project is docs-first: contributions are mostly markdown, agent rules, and governance — not application code in v1.

## Quick links

- [Documentation hub](docs/README.md)
- [Contribution model](docs/governance/contribution-model.md)
- [Quality bar](docs/governance/quality-bar.md)
- [Decisions backlog](docs/governance/decisions-backlog.md)

## Ways to contribute

### Fix or clarify documentation

Small typos and clarifications are welcome.

### Add a component spec

1. Copy [docs/components/_template/](docs/components/_template/) to `docs/components/your-component/`.
2. Fill `metadata.json` and every section of `spec.md`, especially **Accessibility**.
3. Add a row to the Components table in [docs/README.md](docs/README.md).

### Add a pattern

1. Copy [docs/patterns/_template.md](docs/patterns/_template.md) to `docs/patterns/your-pattern.md`.
2. Reference existing or planned components in the Composition table.
3. Add a row to the Patterns table in [docs/README.md](docs/README.md).

### Improve foundations or vision

Edit files in `docs/foundations/` or `docs/vision/`. Keep language beginner-friendly. Link related docs.

### Log open issues

Add entries to [docs/governance/decisions-backlog.md](docs/governance/decisions-backlog.md) when you find gaps — agents should do this too.

## Agent-assisted work

If an AI agent helped draft your contribution:

- You are responsible for reviewing accuracy and accessibility.
- Do not merge conflicting or invented guidelines.
